## Phase Goal

**As a** trader, **I want to** ask the AI to analyze and trade for me, **so that** I can act through conversation.

## Acceptance Criteria (this plan)

- [ ] A chat error (502) shows inline in the panel and the user's typed input is kept (CHAT-04)
- [ ] A loading indicator shows while the user waits for the reply and is gone from the DOM when idle (CHAT-02)
- [ ] Quick-prompt chips offer starter questions with no mock-trigger keywords, and a click asks the question (CHAT-06)
- [ ] The user can send with Enter, add a newline with Shift+Enter, and the conversation scrolls to the newest message (CHAT-01, composer and scroll half)

- **CHAT-02 (unclassified edge, unresolved, review manually).** The probe could not classify the loading requirement.
