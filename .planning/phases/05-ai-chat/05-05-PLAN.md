- **Chat state stays in `ChatDock`, not `Dashboard` (05-RESEARCH Pattern 1).** The UI-SPEC allows either; `ChatDock` owns both the `aside` width and the hook, so `Dashboard` needs no collapsed flag.
- **The collapse button is local to `ChatDock.tsx`.** It is six lines and used once; it shares the `chat-toggle` testid with the rail button, and only one of them is ever mounted.
- **The rail keeps `data-testid="chat-panel"`.** `chat.spec.ts` checks that `chat-panel` is visible, so the rail carries it too (UI-SPEC Collapsed rail).
- **Scroll position after expand.** `ChatTranscript`'s scroll effect runs on mount, so an expand returns to the newest message; the real-browser result is the UAT backstop.
- **No unread indicator on the rail (D-06).** A reply that arrives while collapsed shows only after expand; the refresh and highlight still run.
