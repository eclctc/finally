## Flagged Assumptions

- **Flash on row mount.** A row that mounts after its ticker already has an entry whose `flash` is set (for example right after an add) flashes once, because that entry is a real recent move. No extra state is added to suppress it.
- **Flash visibility in Firefox and Safari** (03-RESEARCH A2) is not tested. If the 50 ms hold does not paint there, the fix is to raise `FLASH_HOLD_MS` to 100, which also worked in Chromium. Checked visually at the Plan 03-05 UAT.
