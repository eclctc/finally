> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, tight inline padding |
| sm | 8px | Gap between a label and its value, button inner padding (y), chip gaps, panel title strip and table cell horizontal padding (`px-2`), input horizontal padding |
| md | 16px | Header horizontal padding (`px-4`), default gap between controls |
| lg | 24px | Gap between groups inside a panel, remove-button hit box |
| xl | 32px | Header gap between the two figure groups (`gap-8`), panel title strip height (`h-8`) |
| 2xl | 48px | Reserved (empty-state vertical padding in later phases) |
| 3xl | 64px | Reserved (sparkline width) |

Fixed component dimensions (also multiples of 4):

| Element | Size |
|---------|------|
| App header | 56px high (`h-14`) |
| Panel title strip | 32px high (`h-8`) |
| Table / watchlist row | 28px high |
| Input and button | 28px high |
| Sparkline | 64px wide (min 48px) by 20px high |
| Watchlist column | `minmax(300px, 340px)` |
| Right chat column | 360px (collapsed rail: 40px, Phase 5) |
| Trade panel column | 260px |
| Minimum page width | 1024px (`min-w-[1024px]`) |

Exceptions:
- 1px hairlines: the `gap-px` grid gutters (they show `bg-line` between panels) and all 1px borders. Reason: a gutter wider than one pixel would cost data area in a dense terminal, and the 1px `bg-line` gap doubles as the panel border.
- 10px connection dot (`size-2.5`, shipped in the Plan 01-03 Header markup). Reason: it is a status glyph, not layout spacing. 8px reads too small beside 20px display text and 12px or 16px dominates the header; 10px is the Tailwind step Plan 01-03 already uses.
- Controls are 28px, below the 44px touch-target guideline. This is a deliberate desktop-first, data-dense choice (PLAN.md section 2). Tablet is "functional", not touch-optimised.

## Typography

Four sizes, two weights. Body line height 1.5 (the Tailwind preflight value, inherited); heading and display line height 1.25 (`leading-tight`).

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Label | 11px (`text-[11px]`) | 400 regular (600 semibold for panel titles) | 1.5 | Figure labels ("Portfolio value", "Cash"), panel titles, table column heads, chart tooltips, timestamps |
| Body | 13px (shipped `body` size) | 400 regular (600 semibold for ticker symbols) | 1.5 | Table and watchlist rows, inputs, buttons, chat messages, inline errors |
| Heading | 18px (`text-lg`) | 600 semibold | 1.25 | "FinAlly" wordmark only |
| Display | 20px (`text-xl`) | 400 regular | 1.25 | `total-value` header figure only |

Rules:
- Weights are exactly 400 and 600. Never use `font-medium`, `font-bold` or any other weight.
- Every number (prices, quantities, P&L, percentages, cash, total) uses the shipped `.figures` class: mono stack with `tabular-nums`, right-aligned in tables.
- Labels are sentence case, not uppercase.
- Text never wraps inside numeric cells (`whitespace-nowrap`).

## Color

Tokens are the shipped `@theme static` values; no hex changes. Always reference them as Tailwind utilities or `var(--color-*)`. Never write a raw hex in a component and never use pure black (`#000`, `bg-black`).

| Role | Token / Value | Usage |
|------|---------------|-------|
| Dominant (60%) | `surface` `#0d1117` | Page canvas, input wells, chart plot wells, chat transcript well, tooltips, selected-row fill |
| Secondary (30%) | `panel` `#1a1a2e` | App header and panel bodies (`bg-panel`); `line` `#30363d` for all borders and grid gutters; `text` `#d5dce6` primary text; `muted` `#7b8698` labels |
| Accent (10%) | `accent` `#ecad0a` | See reserved list below |
| Primary blue | `primary` `#209dd7` | Interactive affordances and data ink: keyboard focus ring, input focus border, main chart line, P&L line, text links |
| Submit purple | `submit` `#753991` | Submit buttons only (white label text): Buy, Sell, Add, Send |
| Up | `up` `#2fbf71` | Uptick flash, positive change and P&L, connected dot, profit heatmap tiles |
| Down | `down` `#f0524f` | Downtick flash, negative change and P&L, disconnected dot, error text, hover state of remove buttons, loss heatmap tiles |

The 60/30 split is by role, not strict area: panels tile the canvas with 1px gutters, and later phases put `surface` wells inside panels.

Destructive color: `down` `#f0524f`, used only for error text and the hover state of the remove-ticker button. There are no destructive confirmations in this product.

Accent reserved for (exhaustive, never "all interactive elements"):
1. The "Ally" half of the wordmark
2. The `total-value` figure in the header
3. The ticker symbol text of the currently selected watchlist row (Phase 3)
4. The yellow "reconnecting" state of the connection dot (the same token, `bg-accent`)

Semantic rules:
- Green and red mean price direction or P&L only (plus connected / disconnected on the dot, and errors for red). Never use them for decoration or for Buy / Sell buttons.
- Buy and Sell are both purple; the label text distinguishes them.
- Contrast (computed): `text` on `panel` is above 10:1; `muted` `#7b8698` on `panel` is about 4.6:1 and on `surface` is higher, so `muted` is allowed for 11px text but nothing dimmer may be introduced; white on `submit` is about 7.6:1.
- Flash colors: `bg-up/25` and `bg-down/25` (Tailwind opacity modifier on the shipped tokens; no new tokens).

## Layout Contract

Fixed terminal grid, no drag, resize or layout persistence. This is the Plan 01-03 template, recorded here as the shared layout for all later phases.

```
+--------------------------------------------------------------------------------+
| Header 56px   FinAlly            Portfolio value   Cash        (dot)           |
+---------------+-------------------------------------------+--------------------+
| Watchlist     | Chart (span 2 of 3)         | Trade 260px | AI Chat 360px      |
| 300-340px     +--------------+--------------+-------------+ (full height,      |
| full height   | Heatmap      | P&L (span 2)               |  right of all)     |
|               +--------------+----------------------------+                    |
|               | Positions (span 3)                        |                    |
+---------------+-------------------------------------------+--------------------+
```

- Root: `flex h-screen min-w-[1024px] flex-col bg-surface text-text`. The document never scrolls vertically; each panel body owns its own scroll (`overflow-y-auto`).
- Below the header: `flex min-h-0 flex-1 gap-px bg-line`. The `gap-px` over `bg-line` draws the 1px panel borders between panels.
- Left of the chat column: `main` as `grid min-h-0 flex-1 grid-cols-[minmax(300px,340px)_1fr] gap-px`. Right of that: `aside` at `w-[360px] shrink-0`.
- Center grid: `grid-cols-[1fr_1fr_260px]` and `grid-rows-[minmax(0,1.25fr)_minmax(0,1fr)_minmax(0,0.85fr)]`. At the 1600x1000 E2E viewport the rows resolve to about 366 / 293 / 249px.
- Panel: `section` with `flex min-h-0 flex-col border border-line bg-panel`, a `h-8 px-2` title strip (`text-[11px] font-semibold text-muted`), then a `min-h-0 flex-1` body.
- Below 1024px wide the page scrolls horizontally rather than reflowing. Portrait tablets are therefore "functional", not optimised (PLAN.md: "responsive but desktop-first").
- Every `data-testid` comes from the shared `testIds` module, never a string literal. Phase 1 attaches only `watchlist`, `heatmap`, `pnl-chart`, `positions-table`, `chat-panel` (panel wrappers), plus `cash-balance`, `total-value`, `connection-status` in the header. It must not attach `watchlist-row-*` or `main-chart` (the specs count rows and read `data-ticker`).

### Header (Phase 1)

- Container: `flex h-14 shrink-0 items-center border-b border-line bg-panel px-4`.
- Visual anchor: `total-value` is the sole focal figure of the Phase 1 shell. It is the only 20px element and the only accent-colored figure, so the eye lands on it first; the wordmark is secondary, and `Cash` is deliberately quieter (13px, `text-text`).
- Left: wordmark, Heading style (18px / 600 / `leading-tight`), `Fin` in `text-text` and `Ally` in `text-accent`.
- Right group (`ml-auto flex items-center gap-8`), in order:
  0. Error line, rendered only after a failed `/api/portfolio` request: `Portfolio unavailable. Reload the page to try again.` (`role="alert"`, Label 11px, `text-down`, `whitespace-nowrap`, `shrink-0`). It is a sibling of the figure pairs, never inside `cash-balance` or `total-value`. Absent from the DOM while loading and after success. About 300px wide, so the header still fits at the 1024px minimum.
  1. `Portfolio value` (Label, `text-muted`) above `total-value` (Display 20px, `text-accent`, `.figures`).
  2. `Cash` (Label, `text-muted`) above `cash-balance` (Body 13px, `text-text`, `.figures`).
  3. Connection dot: 10px circle, `rounded-full`, `data-status` / `title` / `aria-label`; Phase 1 is `disconnected` with `bg-down`.
- Each label/figure pair is a column stack with `gap-xs` between label and figure, right-aligned.
- Dot mapping (Phase 3 wires it): `connected` `bg-up`, `reconnecting` `bg-accent`, `disconnected` `bg-down`. Color is never the only signal: `title` and `aria-label` carry the state name.

## Shared Interaction Patterns (for Phases 3 to 5)

Defined once here so later plans do not re-decide them.

**Number display**
- Header `cash-balance` and `total-value`: `formatCurrency` (`$10,000.00`).
- Watchlist and chart prices: `formatPrice` (`1,234.57`, no `$`).
- Quantity: `formatQuantity` (up to 4 decimals, trailing zeros trimmed).
- Change and P&L %: `formatPercent` (`+1.23%`). Dollar P&L: `formatCurrency` with the sign from the formatter.
- Positive `text-up`, negative `text-down`, zero `text-muted`. Daily change % is computed from `open_price`, never from `change_percent`.

**Price flash (LIVE-04)**
- On a changed price only, apply `bg-up/25` (uptick) or `bg-down/25` (downtick) to the price cell, then transition the background to transparent over 500ms (`transition-colors duration-500 ease-out`). Remove the class after the fade.
- Flash only when the price value actually changes, not on every SSE frame.
- Under `prefers-reduced-motion: reduce`, drop the transition and the background; show the change by the text color alone.

**Rows and tables**
- Row height 28px, `px-2` cells, numeric columns right-aligned `.figures`, text columns left-aligned. Column heads are Label style in `text-muted` with a `border-b border-line`. No zebra striping.
- Hover: `hover:bg-surface/60`. Selected watchlist row: `bg-surface` fill and ticker symbol in `text-accent` (600). Rows are keyboard focusable (`tabIndex=0`); Enter or Space selects. The remove button stops propagation so it does not select the row.
- A row with no price yet still renders with `--`.
- Overflowing lists scroll inside the panel body (`overflow-y-auto`); the page never grows.

**Controls**
- Input: 28px high, `bg-surface`, `border border-line`, `px-2`, Body text. On focus the border becomes `border-primary`; add no glow. Placeholder uses `text-muted`.
- Submit button: 28px high, `bg-submit`, white Body text at weight 600, `px-4`. Hover is `brightness-110`. Disabled is `opacity-50 cursor-not-allowed`, and the button is disabled while its request is in flight.
- Keyboard focus ring for any interactive element: `focus-visible:outline-2 outline-primary`. The 2px outline is the one non-multiple-of-4 stroke width and is accepted as a hairline-class exception.
- Ticker inputs uppercase as the user types; Enter submits the watchlist add.

**Charts (Recharts only, `isAnimationActive={false}` everywhere)**
- Plot well `bg-surface`; grid lines `line` color; axis text Label style in `muted`. No legend.
- Main chart line and P&L line: `primary`. Session-open reference line and the $10,000 P&L baseline: dashed, `muted`.
- Sparkline: no axes or tooltip, stroke `up` or `down` by net direction since load.
- Tooltip: `bg-surface border border-line`, Label style, values via the shared formatters.
- Heatmap tiles: fill `up` or `down` with intensity scaled by P&L % and clamped at plus or minus 5%; near zero uses `line`. Tile label is ticker in `text` (600), plus P&L % when the tile is large enough. 1px `surface` gap between tiles.
- Every chart container has a non-zero explicit height (the grid rows provide it) and keeps its testid mounted in the empty state.

**Chat (Phase 5)**
- Open on load. Collapse folds the column to a 40px rail with a `‹` / `›` toggle; transcript state lives in the parent, so collapse never loses the conversation.
- User messages right-aligned on a `surface` bubble; assistant messages left-aligned on a `panel`-with-`line`-border bubble. Action chips sit under the assistant message that produced them and are not `chat-message` elements.
- The transcript auto-scrolls to the newest message. Input is Body text; Enter sends, Shift+Enter inserts a newline. The loading line and error line are rendered conditionally, never hidden.

**Global**
- Dark only. Set `color-scheme: dark` on `html` in the first phase that renders form controls or scrollable regions, so native scrollbars and inputs match.
- No modals, dialogs, toasts or confirmation steps anywhere.

## Deviations and Reconciliations

Shipped tokens are unchanged. Compared with `01-03-PLAN.md` (not yet executed), small markup deltas are needed so the type scale holds to four sizes and two weights, the spacing scale holds to the standard set, and the header has an error path. Deltas 1 to 3 change no testid, text string or test assertion. Delta 4 adds one new text node outside the testid elements. Delta 5 changes a padding class only.

| # | Plan 01-03 says | This spec requires | Reason |
|---|-----------------|--------------------|--------|
| 1 | `Panel` title `h2`: `text-[12px] font-medium` | `text-[11px] font-semibold` (and `truncate`) | The plan introduced a 12px size and a 500 weight. That gives five sizes and three weights; the contract allows four and two. |
| 2 | Wordmark `text-lg font-semibold` and `total-value` `figures text-xl text-accent` | Add `leading-tight` to both | Tailwind's default `text-lg` and `text-xl` line heights are about 1.56 and 1.4. The contract declares 1.25 for Heading and Display. |
| 3 | Connection dot has `data-status` and `title` | Also set `aria-label` to the same string | Additive accessibility only. |
| 4 | `Header.tsx` has no catch: a failed `request<PortfolioSummary>("/api/portfolio")` leaves `--` and nothing else | Hold a boolean `failed` state set by `.catch(() => setFailed(true))` on that one request. When true, render `<span role="alert" className="shrink-0 whitespace-nowrap text-[11px] text-down">Portfolio unavailable. Reload the page to try again.</span>` as the first child of the right group (before the `Portfolio value` pair). `cash-balance` and `total-value` still render exactly `--` and stay free of any other text. Add one Header test: with fetch rejecting, both testid elements have textContent `--` and the alert text is present. | Every error state for a data-bound element needs copy plus a solution path. This is a user-visible state, not defensive code: it adds one boolean and one message, no retry logic. |
| 5 | `Panel` title strip `header`: `px-3` | `px-2` (8px). Any table cell padding added in later phases also uses `px-2`. | 12px was not in the standard spacing set (4, 8, 16, 24, 32, 48, 64). 8px matches the input padding and keeps data-dense rows tight. |

Everything else in Plan 01-03 (header and panel markup, grid template, `--` loading text, wrapper testids, container-served shell) is adopted as written. Plans 01-02 and 01-04 have no visual output and need no change.
