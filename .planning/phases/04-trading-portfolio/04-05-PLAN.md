## Flagged Assumptions

- **`border-separate border-spacing-0` instead of the UI-SPEC's `border-collapse`.** The UI-SPEC also requires the head to stay pinned and aligned (backstop). In a collapsed-border table, the borders of sticky cells scroll away with the body (RESEARCH Pattern 7, assumption A1). With `border-separate border-spacing-0` and a `border-b` on each cell, the table looks the same and the head border stays pinned. Sticky is set on the `th` cells, the portable form.
- **The empty `P&L` column width is "remaining"**: the fifth `col` has no width class, so `table-fixed` gives it the rest of the 638px panel.
- **Prohibition recall breadcrumb (canon, not minted):** tickers rendered as HTML would be canon XSS; React renders them as text (T-04-14).
